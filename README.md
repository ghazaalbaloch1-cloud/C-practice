# C# Practice Lab

A hands-on C# practice repository for learning modern C# with .NET 10 and VS Code.

## Setup

```powershell
dotnet --version
git clone https://github.com/ghazaalbaloch1-cloud/C-practice.git
cd C-practice
```

Open the repository in VS Code:

```powershell
code .
```

## Roadmap

1. Basics — variables, data types, constants
2. Input & Output — Console.ReadLine, parsing, formatting
3. Conditions — if, else, else-if, switch
4. Loops — for, while, do-while, foreach
5. Arrays — indexing, traversal, searching
6. Methods — parameters, return values, scope
7. Strings — common string operations
8. Collections — List, Dictionary, HashSet
9. Exception Handling — try/catch/finally
10. OOP — classes, objects, constructors, encapsulation
11. Inheritance & Polymorphism
12. Interfaces & Abstraction
13. File Handling
14. LINQ
15. Mini Projects

## How to practice

Each module is a separate .NET console project. Enter its folder and run:

```powershell
dotnet run
```

Do not just read the solution. First try the TODO yourself, then compare.
